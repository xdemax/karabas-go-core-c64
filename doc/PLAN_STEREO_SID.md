# Stereo SID на Mini G — оценка и план

Дата: 2026-11-11.

## 1. Что уже есть

- `fpga64_sid_iec.vhd` (MiSTer) уже имеет два селектора `sid_sel_l` /
  `sid_sel_r`, `sid_mode`, `audio_l/audio_r` и порты `sid_*`.
- `src/rtl/sid/sid_top.v` — **обёртка с одним `sid8580`**: правый канал
  сейчас просто копирует левый:
  ```verilog
  assign audio_l = audio;
  assign audio_r = audio;
  ```
- `c64_machine.v` разводит `audio_l/audio_r` в HDMI и PCM5102. Оба выхода
  стерео, дополнительного железа не нужно.
- В MiSTer `sid_top.sv` есть `DUAL=1` — два чипа, отдельные регистры и
  фильтры; его и надо вернуть/портировать.

## 2. Что нужно сделать

1. Вернуть DUAL-вариант `sid_top` (два `sid8580`, отдельные регистры,
   фильтры, `fc_offset`, `pot`).
2. Выбрать режим адресов второго SID:
   - `$D400/$D420` (dual SID, `sid_mode`),
   - `$D500` / `$DE00-$DF00` (как в MiSTer/Tang);
   - проверить `sid_sel_l/r` из `fpga64_sid_iec`.
3. Добавить OSD `S` item: `Stereo SID` (Off / $D420 / $D500) и, при
   желании, `SID type` (8580/6581).
4. Развести L/R на HDMI и PCM5102 (порты уже есть); проверить уровни/DC.
5. Тест: стерео-разделение, SID-демо, отсутствие записи не в тот чип,
   Timing 0.

## 3. Ресурсы (оценка)

Текущая сборка (F CRT, `529fe67b`, FAST):

| Ресурс | Занято | Свободно |
|---|---:|---:|
| LUT | 11 989 / 15 032 (79%) | ~3 000 |
| Slices | 3 627 / 3 758 (96%) | ~130 |
| RAMB16 | ~46 / 52 | ~6 |

Второй `sid8580` ориентировочно:

- **+1.5…2 тыс. LUT**;
- **+400…600 slices**;
- 0…2 RAMB16.

LUT-запас есть, **слайсов почти нет**. В текущем виде второй SID, скорее
всего, **не влезет**. Перед DUAL надо:

- убрать отладочные 8 квадратов и мёртвые порты/очереди;
- освободить 200–400 слайсов (CRT-мапперы/видео/неиспользуемые FL-пути);
- либо использовать облегчённый SID (общий фильтр/одна модель) — звук
  будет хуже;
- либо сделать DUAL только для 8580 без второй модели 6581.

Точную цифру даст пробная DUAL-сборка: `sid_top` DUAL=1, остальное без
изменений, посмотреть `_map.mrp` и Timing.

## 4. Стоимость

- **Железо: 0** — второй SID это логика FPGA; PCM5102/HDMI уже стерео.
- **Работа:** порт DUAL + OSD + маршрутизация — несколько часов;
  дальше 2–3 сборки/теста.
- **Риск:** не влезет по слайсам; тогда чистка/урезание или отказ от
  полноценного второго фильтра.

## 5. Порядок

1. Сначала добить CRT/Timing 0 (текущая задача).
2. Убрать отладку/мёртвый код, получить запас слайсов.
3. Пробная DUAL-сборка → точные LUT/slices/BRAM/Timing.
4. Если влезает — OSD и тесты; если нет — решить, что урезать.
